# Equaterra Invest Website

A luxury real estate website for Equaterra Invest, a Serbian property developer specializing in urban residential projects.

## Project Overview

Equaterra Invest is a modern, responsive website showcasing luxury residential properties in Novi Sad, Serbia. The site features multiple pages with an elegant design using custom color palettes and serif typography for a premium feel.

## Features

- **Responsive Design** - Mobile-first approach with Tailwind CSS
- **Multi-page Layout** - Landing page, about us, and contact pages
- **Featured Projects** - Showcase of the Prvomajska 10 project in Telep, Novi Sad
- **Professional Styling** - Custom gold (#b8935a), dark navy (#0d1b2a), and cream (#f1ebe1) color scheme
- **Google Maps Integration** - Embedded location map on contact page
- **Contact Forms** - Responsive contact forms with transparent styling

## Pages

### 1. **index.html** - Landing Page
- Hero section with background imagery
- Featured project showcase
- Reservation call-to-action section
- Footer with navigation and contact information

### 2. **o-nama.html** - About Us
- Company story and vision ("Ko smo mi" section)
- Core values display ("Naše vrednosti" section)
- Process workflow ("Kako radimo" section with 3-step process)

### 3. **kontakt.html** - Contact
- Contact information section
- Contact form
- Google Maps location display
- Office details and hours

## Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **JavaScript** - Puppeteer for automated screenshots
- **Fonts** - EB Garamond (serif), Cormorant Garamond (serif), Inter (sans-serif)
